MODEL FOLDER STRUCTURE (2026-11-27)
===================================

code/flow        current Stokes-Darcy flow models
code/transport   transport models (nephron diffusion check, older 2D/3D models)
code/coupled     flow-transport coupling model

mesh_generation  final SWC-to-UGX pipeline, refinement and quality checks,
                 trace repair tools
mesh_generation/meshes/<YYYY-MM-DD>_<desc>/
                 kept generated meshes, each with a README

Results/<YYYY-MM-DD>_<desc>/
                 results the user chose to keep (ignored by Git)

docs             dated scientific notes and handoffs
Nephron traces   SWC morphology inputs and repaired traces
grids            compact UG4 sample grids used by the older transport models
ug4_build_overlay  patches and sources that reproduce the UG4 build
codex_history    notes and rollouts from earlier sessions

Only working code, the meshes it uses and kept results live here. Debugging
and test output is written outside Model and deleted after the findings are
recorded in docs/ (see AGENTS.md, "Clean workspace").

Repository boundary
-------------------
The Model directory is the lua_codes Git repository root. The folder is
normally on branch main.
