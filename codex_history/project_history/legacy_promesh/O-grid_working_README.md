## Cross-sectional O-grid topology

With the default `-ogrid 16`, every axial station contains:

1. One centerline vertex.
2. Sixteen internal Lumen-ring vertices at 50% of the lumen radius.
3. Sixteen Apical vertices at the Lumen/Membrane interface.
4. Sixteen internal Membrane-ring vertices halfway through the membrane.
5. Sixteen Basolateral vertices at the Membrane/Inter interface.

The Lumen consists of a smaller prismatic core and an outer hexahedral layer.
The Membrane consists of two radial hexahedral layers. This guarantees that the
coarse Lumen and Membrane subsets both contain internal vertices rather than
placing all their vertices only on boundary subsets.

For `-ogrid N`, each complete Inlet and Outlet contains `2*N` faces: `N` inner
triangles and `N` outer quadrilaterals.

## Generated subsets

For one nephron:

- `Membrane`: membrane volume and its internal entities
- `Lumen`: lumen volume and its internal entities
- `Basolateral`: Membrane/Inter interface
- `Apical`: Lumen/Membrane interface
- `Inlet`: complete low-axial Lumen cap
- `Outlet`: complete high-axial Lumen cap
- `OuterWall`: exterior boundary of the surrounding box
- `Inter`: extracellular/interstitial tetrahedral volume

For multiple nephrons, biological subsets are indexed by input order:
`Membrane_1`, `Lumen_1`, `Basolateral_1`, `Apical_1`, `Inlet_1`, `Outlet_1`,
then the corresponding `_2`, `_3`, and so on. `Inter` and `OuterWall` are shared.

## Projector and refinement behavior

- The NeuriteProjector is assigned only to Apical and Basolateral surfaces.
- Lumen, Membrane, Inter, caps, and OuterWall are not projected onto a tube.
- `npSurfParams` and the NeuriteProjector are serialized in the coarse UGX.
- The single-SWC script can generate projected refinement levels internally.
- `_refined_1.ugx`, `_refined_2.ugx`, etc. contain only the requested flat level,
  not a visible stack of coarser levels.
- Flat refined files are intended for inspection or solvers. Generate additional
  projected levels by rerunning the pipeline from the coarse mesh with a larger
  `-numRefs` value.

## Mesh construction and fixes included

1. Smooth and resample each SWC centerline.
2. Replace radii with the requested constant outer radius.
3. Construct matching nested O-grid rings using a parallel-transport frame.
4. Construct internal Lumen and Membrane radial vertex layers.
5. Create and pre-refine the padded outer-box surface.
6. Tetrahedralize only the exterior Inter region.
7. Remove overlapping TetGen cells from Lumen and Membrane.
8. Preserve exact Basolateral and OuterWall boundary topology.
9. Classify Inter faces, edges, and vertices without leaking them into Membrane.
10. Remove orphan and duplicate entities and repair element orientations before
    final subset indexing.
11. Identify Inlet and Outlet using true terminal Lumen ownership and axial
    position, excluding internal Lumen faces.
12. Preserve Apical rim projector parameters through repeated refinement.
13. Validate and repair volume orientation after every generated projected level.
14. Assign terminal-cap edges with deterministic priority: shared Apical rim
    edges remain Apical, while all other cap edges are Inlet/Outlet. This keeps
    every refined Lumen vertex in the flow approximation-space closure and
    prevents missing-DoF and local-matrix corruption during Navier--Stokes
    assembly.

## Single-SWC command

From the `ProMeshFiles` directory:

```bash
../bin/ugshell \
  -ex swc_to_neurite_projector_nephron_final_pipeline.lua \
  -swc "/absolute/path/to/nephron.swc" \
  -smoother "./quadratic_interpolate_swc.py" \
  -out "/absolute/path/to/output.ugx" \
  -numRefs 1
```

Example with explicit controls:

```bash
../bin/ugshell \
  -ex swc_to_neurite_projector_nephron_final_pipeline.lua \
  -swc "/absolute/path/to/nephron.swc" \
  -smoother "./quadratic_interpolate_swc.py" \
  -out "/absolute/path/to/output.ugx" \
  -ogrid 16 \
  -anisotropy 2 \
  -BoxRefs 5 \
  -numRefs 1
```

## Multiple-SWC command

Input numbering must be contiguous. Do not provide `-swc1` and `-swc3` without
also providing `-swc2`.

```bash
../bin/ugshell \
  -ex swc_to_neurite_projector_multiple_nephrons.lua \
  -swc1 "/absolute/path/to/nephron_1.swc" \
  -swc2 "/absolute/path/to/nephron_2.swc" \
  -swc3 "/absolute/path/to/nephron_3.swc" \
  -smoother "./quadratic_interpolate_swc.py" \
  -out "/absolute/path/to/multiple_nephrons.ugx" \
  -ogrid 16 \
  -anisotropy 2 \
  -BoxRefs 5
```

At least two SWCs are required. Add `-swc4`, `-swc5`, and further inputs as
needed. The current multiple-SWC script writes the projector-backed coarse mesh.
